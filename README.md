# Instagram Image Extractor Extension

A simple and efficient Google Chrome extension to list and download all images from the instagram web page.

---

## 🌐 Overview

**Images Extractor** is designed to help users effortlessly collectphotos from instagram webpage. With just a click, you can view, filter, and download images for content creators, researchers, or anyone needing bulk media retrieval.

Developed by **ITS - Info Twist Solutions**  
🔗 [its.net.in](https://its.net.in)

---

## 🚀 Features

- 🔍 Extracts all visible images and videos from the current tab
- 📥 One-click to download option
- 🖼 Preview media before saving
- 🧹 Filter out with alt text
- ⚡ Fast, lightweight, and privacy-friendly

## 🔧 Installation

1. Clone or download this repository:
   ```bash
   git clone https://github.com/sanuas/instagram-image-extractor-extension.git

## 🧷 How to Pack It:

1. Place all files in one folder.
2. Right-click → "Compress"/"Send to ZIP" → Name it `instagram_image_extractor.zip`.
3. Go to `chrome://extensions/` → Enable **Developer mode** → Click **Load unpacked** → Select the folder.
